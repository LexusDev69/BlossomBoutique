# Publish Blossom on InfinityFree

This project uses PHP and MySQL, so it needs PHP hosting with a MySQL database. This guide is for the current InfinityFree panel and its free subdomain.

## 1. Create the hosting account and database

1. Create an InfinityFree account and add a free subdomain.
2. In the hosting control panel, create a MySQL database. Copy its **database name, database username, password, and hostname** exactly as shown. InfinityFree database names and users commonly include an account prefix; do not use the XAMPP values.
3. Open phpMyAdmin from that hosting account and select the new database.
4. Import `database/schema.infinityfree.sql` from the deployment ZIP. It omits local `CREATE DATABASE` and `USE` commands because the hosting panel creates and selects the database for you.

## 2. Set the hosting configuration

Edit `config/config.php` in the deployment copy (not the original project) and set these values near the top:

```php
$appPublicUrl = 'https://YOUR-SUBDOMAIN';
```

Use the site origin only (scheme and domain, with a subfolder only if applicable). The app adds the PayRex return and webhook paths itself.

Then set the database constants to the values from InfinityFree:

```php
define('BASE_URL', '');
define('DB_HOST', 'YOUR-MYSQL-HOST');
define('DB_USER', 'YOUR-MYSQL-USERNAME');
define('DB_PASS', 'YOUR-MYSQL-PASSWORD');
define('DB_NAME', 'YOUR-MYSQL-DATABASE');
```

`BASE_URL` is empty when the app files are directly in `htdocs`. If you upload the app into a subfolder such as `htdocs/blossom`, set it to `/blossom` and include that subfolder in `$appPublicUrl` as well.

Keep the existing PayRex settings in `config/config.php` when you make these edits. The deployment packager copies the existing file, including its current PayRex configuration; it does not replace or edit PayRex integration files. Before accepting real payments, use the correct production credentials and webhook secret from PayRex and confirm the account is in live mode. Keep credentials private and never commit the deployment ZIP to a public repository.

## 3. Upload the site

1. Run `scripts/Build-InfinityFree.ps1` in PowerShell. It creates a `dist` folder containing both an editable deployment folder and a compressed ZIP.
2. Edit `dist/blossom-infinityfree/config/config.php` with the hosting database settings and public URL above. The ZIP is created before those edits, so compress the edited deployment folder again or upload that folder's contents directly with FTP.
3. Upload the contents of `blossom-infinityfree` into the hosting account's `htdocs` directory using the file manager or FTP. The PHP files should be directly in `htdocs`, alongside folders such as `admin`, `assets`, `config`, and `includes`.
4. Visit your subdomain and check the home page, signup/login, product pages, and checkout.

## 4. Configure PayRex callbacks

In the PayRex dashboard, set the webhook endpoint to:

```text
https://YOUR-SUBDOMAIN/payrex-webhook.php
```

The return URL is generated by the app from its public URL configuration. Complete a test checkout and confirm that PayRex can reach the webhook over HTTPS. Do not share the ZIP or expose your secret keys.

## Updating the site

After editing the original project, run the packager again and upload the changed files. Preserve the hosting database and `config/config.php`; don't overwrite the hosting config with the local XAMPP copy. Export a database backup before importing schema changes or migrations.

Free hosting can have resource and uptime limits. Keep a separate backup of the project and database.
